# 角色提示词 v2 —— 跨姿态「服饰一致性」版

> 适用对象：**14 套皮肤**（lab / night / pajama / sailor / yukata / qipao / santa / office / sport / hanfu / miko / goth / winter / idol）。
> （1.51.0：原来第一格是 `classic` 素绘女仆，已整套退役、换成 `lab` 海洋研究员。）
> 不适用：**canon / swim / deepsea**（已有帧动画，静态图冻结）、**chibi**（Q 版两头身，现有提示词已足够一致）。

---

## 0. 归因：v1 为什么会在八个姿态之间漂

八张立绘是**八次互不相干的文生图**，两次调用之间没有任何记忆。因此"跨姿态一致"这件事
**只有提示词这一个载体**——提示词没写死的每一个细节，模型都会在每一张里**重新掷一次骰子**。

v1 的服装段是一段**散文**，长约 120–160 字，钉住大约 8–12 个属性。而一张立绘上**可辨认的
服装属性有 30 个以上**（面料的哑光/缎面、荷叶边的层数与宽度、领口的形状与开口深度、
袖长与袖口、腰带的宽度与系法、蝴蝶结的大小与位置、裙摆的长度与开衩、袜子的长度与罗纹、
鞋的跟高与鞋头形状、每一处镶边的颜色与宽度……）。**没被写到的二十来个属性全部交给模型即兴发挥。**

**决定性的一条**：本项目自己反复实测出来的规律是——

> 同一个要求写在提示词**开头**会被忽略，写在末尾的**【画面完整性，逐条核对】**里、并且**编号**、
> 并且说清"**不能被什么挡住**"，才会被执行。

（呆毛：写在开头被省略，写进编号清单后一次就有。鲸尾：写在身份段，**其余五套的 39 张一张都没有**；
swim 写成编号 + "不能被头发、裙摆或双腿挡住"之后，八张**一次到位**。）

而 v1 的**末尾清单里没有任何一条是服装**——六套有据可查的皮肤，清单项一律只覆盖
头发 / 呆毛 / 鲸鳍耳 / 发尾 / 手指 / 五官（canon 六条，无一条服装）。**服装是全篇唯一
"只出现在开头、不进末尾清单"的部分**，于是它是被忽略得最彻底的部分。

**唯一的反证也印证了这条规律**：swim 的清单曾经补到 ⑪ 条，其中 ⑨ 是"**泳装必须清楚可辨：
三角罩杯 + 颈后与后背的细系带**"——那一条正是因为 happy 那张把上衣画成了横条才补的。

结论：**不是"提示词不够长"，是服装没有进入那个被真正执行的通道。**

## 2. 固定段（14 套逐字共用，一个字都不改）

### 2.1 第一段：绿幕（必须放最前）

```
【背景要求，最重要】整张图必须是纯绿色背景（严格是鲜艳的纯绿 rgb(0,255,0)），从头到脚均匀铺满、
没有任何渐变、纹理、暗角、阴影或其他物体，角色完全被这块纯绿色包围，角色四周留出一圈纯绿色空隙。
绝对不要黑色背景、不要深色背景、不要白色背景、不要渐变背景。
```

### 2.2 身份段

```
【发型，注意不是双马尾】一位留着**深蓝色中长直发**的女性：头发**自然披散**下来、长及腰际，
**没有扎成马尾、没有双马尾、没有盘发**；发梢由深蓝**渐变到浅蓝**；额前是**齐刘海**，两侧鬓发垂到肩下。

【头部特征，逐条画出来】
① **呆毛**：头顶正中有一缕头发**向上立起、向前上方弯成一个明显的大圆环**（像一个圈），
   它高出头顶轮廓很多，是独立的一缕，非常醒目；
② **发箍**：戴一条**白色荷叶边女仆发箍**，发箍上别着一个**蓝色鲸鱼造型发夹**。

【耳部，按顺序照画】耳朵不是人类耳朵，是两片鲸鱼胸鳍，长在头部两侧：
① 从头部侧面**贴着头发、向后下方斜掠**，**不是向上竖立、不是向两侧平伸、不是像翅膀张开**；
② **狭长**：根部略宽，向后收窄成一个**尖梢**，外缘一道平滑弧线，有一点厚度感；
③ 配色：**上表面深蓝色、下缘与内侧白色或很浅的蓝白**，深浅分界清楚；
④ **尺寸小巧**：每片长度约为**头宽的四分之一**，不要超过三分之一；
⑤ 没有人类耳朵，没有耳环、耳坠、耳钉，没有任何挂在耳侧的饰物。

【鲸尾】从**腰后**长出一条蓝色鲸尾，尾鳍自然向下，是独立而明显的一块深蓝到浅蓝渐变的形状。

【颈饰】颈部一条细蓝色颈饰。
```

## 3. 姿态段（八选一，含"遮挡条款"——这是 v2 新增的关键）

v1 的姿态段只描述动作，没有交代**这个动作会遮住什么**。sleepy（抱枕挡胸腹）、work（抱笔电挡胸腹）、
eat（捧碗挡胸腹）、happy（举手拉高衣服）恰恰是服装漂移最严重的四格——因为模型必须**自行发明被挡住的部分**。

**v2 的做法：每个姿态都补一句"遮挡条款"，明确"什么可以挡、什么必须在遮挡物周围仍然可见"。**

| 文件 | 姿态段（在 v1 那张表基础上补遮挡条款） |
|---|---|
| `idle.png` | 一手叉腰、一腿微屈、身体微微侧倾，自信而妩媚地看向镜头，嘴角含笑。**服装完全不被遮挡，全部元素必须完整可见。** |
| `happy.png` | 双手举在身体两侧欢呼，闭着眼睛开心大笑，脸颊微红，身体微微后仰。**举起双臂不得改变服装任何元素：袖口、袖长、腰带、裙摆的形状与位置都不变**；举手时腋下与身侧露出的仍是同一件衣服的同一片布料。 |
| `sleepy.png` | 怀里抱着一只蓝色鲸鱼抱枕，抱在胸腹前；半闭着眼睛打盹，困倦地微微低头。**抱枕只允许挡住胸前正中一小块：领口、两侧肩线、腰带、蝴蝶结、裙摆必须从抱枕两侧清楚露出**；抱枕不得改变衣服的画法。 |
| `work.png` | 一手托着一台打开的笔记本电脑，另一手在键盘上打字，认真专注地看着屏幕。**笔电只允许挡住胸前与腹部：领口、肩线、腰带、蝴蝶结、裙摆必须从笔电两侧与下方清楚露出**。 |
| `attn.png` | 身体微微前倾，一只手抬到胸前朝前方招了招；眉头微蹙、认真地直视前方，带着一点催促。**抬起的那只手不得遮住领口与腰带**；服装全部元素完整可见。 |

| `poked.png` | 身体明显往后一缩、双肩微微耸起，一只手抬到胸前摆出「等一下」的姿势（掌心朝前）；眼睛睁得比平时大、眉毛微挑，嘴巴小小地抿着。**那只手不得遮住领口、腰带与蝴蝶结**。 |
| `eat.png` | 双手捧着一碗盛得冒尖的白米饭，捧在胸腹前，闭着眼睛开心地笑，脸颊微红。**饭碗只允许挡住腹部正中：领口、两侧肩线、腰带、蝴蝶结、裙摆必须从饭碗两侧清楚露出**。 |

## 4. 十四套【服装规格】（编号 = 可核对；同一套的八张**逐字相同**）

> 写法规则（沿用本项目实测有效的三条）：
> ① **能数的就写数目**（几层、几个、几条）；② **颜色写死、不写"性感/单薄/高级"这类不可核对的词**；
> ③ 形状类要求写成**几何描述**，并**显式排除**最容易跑偏的那几个东西。

## 6. 出图流程

```bash
# 1. 每套皮肤 8 张：model=gpt / resolution=4K / target_size=2048x3072 / aspect_ratio=2:3
#    quality=high / thinking_level=high / 不传参考图 / 一张一次调用

node tools/assets.mjs --from masters/<skin> --skin <skin>
# 3. 并排验：八张的服装必须先肉眼过一遍 —— "单看一张永远是对的"
# 4. 打包 + 预检
node build.mjs && node verify-wisp.mjs
```

### 验收（必须做，且必须**八张并排**看）

1. **服装**：逐条对第 4 节的编号清单，八张逐条打勾；任何一条在任意一张上不成立 → 重出那一张。
2. **取景**：八张的内容高度占画布 97%–100%，否则切表情时会"缩一圈"（swim/happy 踩过）。
3. **头身比**：约 6.5–7 头身，八张一致（night/attn 踩过：头/高 0.113 vs 其余 0.19–0.25）。
4. **键控**：`assets.mjs` 报的软边比例应为 0.3%–0.7%，超过 5% 直接拒绝。
5. **鲸尾 / 呆毛**：八张都在 —— 这两条是历史重灾区。
