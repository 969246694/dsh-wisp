# 角色提示词（可复用母版）

**这是本插件形象的唯一权威来源。** 改形象 = 改这里 + 重跑生成 + `node tools/assets.mjs`。
每次出图必须**逐字复制**下面的段落，只替换【姿态】那一节 —— 形象靠提示词锚定，不能靠参考图。

---

## 生成参数（每一张都必须一致）

| 参数 | 值 |
|---|---|
| `model` | `"gpt"` |
| `resolution` | `"4K"` |
| `target_size` | `"2048x3072"` |
| `aspect_ratio` | `"2:3"` |
| `quality` | `"high"` |
| `thinking_level` | `"high"` |
| `transparent` | **省略（即 false）** ← 见下方「为什么不用透明背景」 |
| 调用方式 | **一张素材一次调用**，不要在 batch 里混多张 |
| 参考图 | **绝对不传**（`reference_image` / `reference_images` 都不传） |
| 一张图里几个角色 | **只有一个**，提示词里必须写明 |

## 提示词正文（逐字复制）

```
一位留着**深蓝色中长直发**的女性：头发**自然披散**下来、长及腰际，**没有扎成马尾、没有双马尾、没有盘发**；
发梢由深蓝**渐变到浅蓝**；额前是**齐刘海**，两侧鬓发垂到肩下。
**头顶正中有一缕呆毛**：向上立起、向前上方弯成一个大圆环，高出头顶轮廓（社区标识之一）。

身后从腰部长出一条蓝色鲸尾，尾鳍自然向下，必须在画面中清楚可见。

宝蓝色大眼睛；头顶戴白色荷叶边女仆发箍，发箍上别一枚蓝色鲸鱼造型发夹。

**她的耳朵不是人类耳朵，而是一对鲸鱼胸鳍（社区规范的「鲸鳍耳」）**：
① **朝向最重要**：长在头两侧、**向后下方斜掠、几乎贴着头发向后伸展**，不是朝上竖立、不是向两侧平伸。
   （第一版做成了向上外张的大翅膀 —— 用户说"太大了"，实测**问题在朝向不在长度**。）
② **狭长**：根部略宽，向后逐渐收窄成一个**尖梢**，外缘一道平滑弧线，有一点厚度感；
③ **配色是关键**：**上表面深蓝色、下缘与内侧白色或很浅的蓝白**，深浅分界清楚 ——
   这是座头鲸胸鳍正反两面的配色，也是最显眼的识别点；
④ **尺寸小巧**：每片长度约为**头宽的四分之一**，**不要超过三分之一**，绝不要画成翅膀那样大 ——
   耳朵是配角，不该比头还显眼；
⑤ **没有人类耳朵，没有耳环耳坠耳钉，也没有任何挂在耳朵上的饰物。**

**头顶要有一根呆毛**（社区标识之一）：一小缕头发从发箍上方的头顶竖起、顶端向前弯成一个小圆环
（像钩子或小问号），**明显高出头发轮廓、是独立的一缕**。
**这一条必须写进提示词末尾的「画面完整性，逐条核对」清单** —— 只写在开头会被模型省略（实测过）。

颈部一条细蓝色颈饰。

【体型】成年女性的成熟身型：高挑、长腿、细腰，肩颈与锁骨线条优美，曲线明显但不夸张。

【服装】性感的单薄女仆装：深蓝色一字肩细吊带连衣短裙，单层，低领口露出锁骨与肩线；裙摆极短、单层、自然垂落，露出一整条腿；身前罩一件单层白色半身围裙，围裙的荷叶边是深蓝色，围裙带在腰后系成一个深蓝色蝴蝶结；不穿长袜，直接露出双腿；脚穿白色细带高跟凉鞋。

【画风】高质量的现代二次元插画，商业级插画精度：精细的线稿，高密度分明的发丝刻画，眼睛有多层高光与渐变瞳孔，皮肤与布料用柔和细腻的多层过渡阴影与通透的配色，光影层次丰富。保持二次元的动漫面部与身材比例（大而亮的眼睛、小巧的鼻与嘴）。不要照片写实、不要三维渲染感、不要粗糙平涂、不要塑料感。

【姿态】__按情绪替换，见下表__

【画面完整性】画面中只有一个角色。头发是深蓝色中长直发、自然披散，不要画成双马尾、不要马尾、不要盘发、不要白色头发；头顶的大圆环呆毛清楚可见、不能被省略；鲸尾必须可见且与身体连接；发尾干净完整；手指完整；五官清晰。

【背景】纯绿色背景（绿幕）：整张背景是一整片均匀的纯绿色，没有任何渐变、纹理、阴影或其他物体；角色完全被纯绿色包围，不要在地面投下阴影。

【构图】全身直立、脚底贴住画面底边、角色居中。
```

## 第三套皮肤：宵蓝礼服（`night`）

形象要素与母版**逐字相同**（深蓝中长直发、大圆环呆毛、鲸鳍耳、白色荷叶边女仆发箍 + 蓝色鲸鱼发夹、

## 第四套皮肤：宵眠睡衣（`pajama`）

形象要素与旗舰那套**逐字相同**，只替换【服装】段：

```
【服装】宽松的深蓝色长袖睡衣：上衣宽大柔软、领口有一圈白色鲸鱼刺绣、下摆盖住臀部；
下身同色宽松睡裤、裤脚有白色鲸鱼图案；脚穿一双毛绒鲸鱼拖鞋；不穿袜子。
```

五张姿态照第 49 行那张表，一张不改。实测键控 0.48%–0.56% 软边。

> 这一套的用意是**剪影差异**：前三套都是"贴身 + 露腿"，睡衣是"宽松 + 包住腿 + 毛绒拖鞋"，
> 一眼就能分辨她在穿什么。它也让 `sleepy`（抱着鲸鱼抱枕打盹）变得贴切 —— 那是这套里最好的一格。

## 社区规范：她长什么样是有共识的

社区为此专门做了一个开源角色规范项目（**非官方**）：[Neko3000/deepseek-whalechan](https://github.com/Neko3000/deepseek-whalechan)
（[中文 README](https://github.com/Neko3000/deepseek-whalechan/blob/main/README.zh.md)）。它把"鲸鱼娘"的识别点锁定为：

> 精准锁定**发色渐变、鲸鳍耳、呆毛、鲸尾**与女仆装等核心标识

| 锁定标识 | 本插件 | 说明 |
|---|---|---|
| 发色渐变 | ✓ | 深蓝 → 发梢浅蓝 |
| **鲸鳍耳** | ✓（1.16.0 起） | 耳朵本身就是一对鲸鱼胸鳍；此前误做成"耳侧挂鳍形耳饰" |
| **呆毛** | ✗ **尚未实现** | 头顶那缕绕成小圈的头发，社区标识之一 |
| 鲸尾 | ✓ | 腰后一条鲸尾 |
| 女仆装 | 部分 | 社区是长袖全套女仆装 + 白袜皮鞋；本插件是单层吊带短裙（刻意的风格选择） |

**教训**：先去看社区共识，再动手画。我一开始把"鲸"理解成"加一点鲸鱼元素"，于是给她挂了鳍形耳坠、
还把"鳍"写成"鲸鱼鳍造型"——结果出来的是鱼鳍、直板、水滴宝石，绕了三轮。**社区早就把答案写在规范里了。**

## 第五套皮肤：原版女仆（`canon`）—— 对齐社区规范

这一套的目标**不是原创，而是复刻社区共识**。生成参数与前面几套完全一致，提示词如下（逐字复制）。

```
【背景要求，最重要】整张图必须是纯绿色背景（严格是鲜艳的纯绿 rgb(0,255,0)），从头到脚均匀铺满、没有任何渐变、纹理、暗角、阴影或其他物体，角色完全被这块纯绿色包围，角色四周留出一圈纯绿色空隙。绝对不要黑色背景、不要深色背景、不要白色背景、不要渐变背景。

【发型，注意不是双马尾】一位留着**深蓝色中长直发**的少女：头发**自然披散**下来、长及腰际，**没有扎成马尾、没有双马尾、没有盘发**；发梢由深蓝**渐变到浅蓝**；额前是**齐刘海**，两侧鬓发自然垂到肩下。

【头部特征，逐条画出来】
① **呆毛**：头顶正中有一缕头发**向上立起、向前上方弯成一个明显的大圆环**（像一个圈），它高出头顶轮廓很多，是独立的一缕，非常醒目；
② **发箍**：戴一条**白色荷叶边女仆发箍**，发箍**右侧**别着一个**蓝色小蝴蝶结**；
【耳部，按顺序照画】耳朵不是人类耳朵，是两片鲸鱼胸鳍，长在头部两侧、眼睛稍下的位置。
每一片的形状是一片**细长、光滑、末端圆钝的鳍**，像一片长叶子：
① 方向与位置（最关键）：从头部侧面**贴着头发、向外并向下约 35 度**伸出去，**紧贴头侧的头发**、
   往后掠；**不是向上竖立、不是向两侧平伸、不是像翅膀张开**；
② 长度：**较长**，伸出的长度**约等于头的宽度**，明显超出头发轮廓；
③ 宽度：根部略宽、向末端收窄，最宽处约为长度的三分之一，整片是**扁平的**；
④ 轮廓：上缘是一条光滑的弧线，下缘也是一条**光滑连续的弧线**，只有极轻微的自然起伏；
   整片**柔软、圆润**，末梢是**圆钝的小尖**并微微向下弯；
⑤ 颜色：**外表面深蓝色**（与头发同色、边缘一圈深色描边）；**下缘与内侧有一条白色到银灰色的宽带**
   （约占鳍宽的一半），像翻开的内衬 —— **这是最显眼的识别点**；
⑥ 两片左右基本对称。没有人类耳朵，没有耳环、耳坠、耳钉，没有任何挂在耳侧的饰物。

【眼睛】宝蓝色的大眼睛，多层高光与渐变瞳孔，睫毛分明。
```

## 两个工具的分工

| 工具 | 输入 | 什么时候用 |
|---|---|---|
| `tools/assets.mjs` | **绿幕母版**（纯绿底 PNG） | 刚出完图，抠图 + 分档一次做完 |
| `tools/tiers.mjs` | **已经抠好的透明 PNG** | 手上只有成品，或绿幕原图已不在 |

**不要把已经抠过的图再喂给 `assets.mjs`** —— 那是二次抠图，结果依赖"透明像素里是否还残留
绿色"。抠图在这里是幂等的**假象**，不是保证。两个工具都会拒绝明显不对的输入：
`assets.mjs` 在"键控几乎无效"时退出，`tiers.mjs` 在"没有 alpha 通道"时退出。

## 为什么不用透明背景

服务端的 `transparent: true` **会把不该抠的抠掉**：角色是深蓝/浅蓝/白配色，浅蓝渐变的**发梢**与
**鲸尾**最接近浅色底，于是被当成背景切掉 —— 表现是「生成结果变成了短发、鲸尾消失」，极易误判成
模型跑形。实测同一批提示词走服务端透明背景时四张全部丢失发梢与鲸尾。

所以：**出图用绿幕，抠图自己做**（`node tools/assets.mjs`），只有 0.4%–0.7% 的边缘像素需要处理，
发丝一根不丢。

## 耳部写法：两个实测出来的坑（都能复现）

**坑一：不要提"缺口"或"锯齿"** —— 哪怕是用来说"不要锯齿"。

社区的鳍耳下缘确实有极轻微的波浪，我一开始把它当成最重要的识别点写（"下缘有 3 个半圆缺口，像被剪了三刀"），
结果**三份不同写法全都画成了锋利的尖牙/锯子边**（A / B / C 三个版本一次全中）。
更糟的是往里写"不要尖锐的锯齿、不要像锯子"也没用 —— **负面词同样会招来那个形状**。

正确写法：只说**正面**的形状语言 —— "上缘是一条光滑的弧线，下缘也是一条光滑连续的弧线，
只有极轻微的自然起伏"，把"缺口"整个不提。实测这样出来的边缘是干净的（E / F）。

**坑二：尺寸不是主要问题，朝向才是。**

用户反馈"耳朵太大了"时，我把长度从"头宽的三分之一"一路缩到"三分之一"，结果**又缩过头**（E 太小）。
放大社区立绘逐像素核对后发现：社区的鳍其实**很长（约等于头宽）**，问题是它**贴着头发向后下方掠**，
而我做成了**朝上外张的翅膀**。正确写法是把"朝向"写成第①条、并明确否定三种错误朝向
（向上竖、向两侧平伸、像翅膀张开），长度反而要写"约等于头宽"。

**结论**：这几轮下来，纯文生图能做到的是"**同一个设计、一眼认出是同一个角色**"；
做不到**像素级复刻** —— 社区自己的角色一致性工具也是一套训练过的 LoRA（见其 Civitai 模型页），
而不是靠纯提示词。要求像素级一致时，纯文生图这条路是走不通的。

## 写作技巧：要求要放在末尾的清单里

同一个要求写在提示词**开头**会被忽略，写在末尾的**【画面完整性，逐条核对】**里才会被认真执行 ——
**呆毛**就是这么拿到的：第一版写在开头，模型直接省略；写进清单（还编了号）之后一次就有了。
双马尾、鲸尾、发尾完整这些一直生效的项，本来就都在那个清单里。

清单里的每一条都要**可核对**：与其说"画得好看"，不如说"明显高出头发轮廓、是独立的一缕、不能被省略"。

## 三个踩过的坑

### 鲸鱼鳍 ≠ 鱼鳍（写"鳍"就会得到鱼鳍）

原稿写的是「耳侧有鲸鱼鳍造型耳饰」。出来的是一对**带棘刺、有放射状鳍条、边缘锯形**的鱼鳍 ——
那是热带鱼的鳍，不是鲸的。

改了两轮才拿准措辞：

| 措辞 | 结果 |
|---|---|
| 鲸鱼鳍造型耳饰 | ✗ 鱼鳍（带鳍条、棘刺） |
| 细长圆润、像叶片 | ✗ 平滑了，但末端分叉，像羽毛 |
| 柳叶、末端圆钝 | ✗✗ **跑偏成水滴形宝石耳坠**（"水滴/圆钝"把模型带去了宝石） |
| **扁平的长条板、两端磨圆、宽度一致、边缘连续光滑；并显式排除"水滴、宝石、吊坠、羽毛"** | ✓ 扁平的圆头桨板 |

教训：**形状类的要求要写成几何描述（扁平、等宽、圆头、边缘连续），而不是比喻**；比喻会各自联想，
而且负面清单必须列全 —— 光说"不要鱼鳍"不够，还得说清"不是什么"。

## 三个踩过的坑

1. **绿幕要求必须写在第一段**，否则模型可能改画黑底 —— 四角实测 `rgb(0,0,0)`，抠图直接失效。
   若 `assets.mjs` 报「键控几乎无效」，就是这张没听话，重出即可。
2. **不要写「高质量二次元插画」这种笼统说法**，它会推向韩系半写实（头发变短、体型成熟化），
   角色设定随之崩掉；必须写成「商业级二次元插画 + 二次元的动漫面部与身材比例 + 不要照片写实/
   三维渲染感/粗糙平涂」。
3. **不要把「少女体型」和「性感」写在一起。** 当前设定是**成年女性**；这一点不要在改服装时改掉。
